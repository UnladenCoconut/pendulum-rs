# pendulum-rs

The aim of this project is to extend a simple [2D simulation of a double pendulum](https://github.com/UnladenCoconut/Lagrangian) to the 3D case, using better numerical solvers (e.g. Runge-Kutta-Nystrom) in compute shaders for more accurate rendering.

Derivation of the Lagrangian and documentation of math written up [here](Lagrangian.pdf).
